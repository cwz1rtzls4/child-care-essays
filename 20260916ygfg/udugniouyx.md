# 想提高孩子的免疫力？这7点你得做到！

> 更新时间：2026-09-16 (UTC+8)

孩子生病，一家人跟着揪心。

提高孩子的免疫力，成了众妈妈心心念的大事！

做好这7点，提高孩子免疫力，so easy！

1**母乳喂养**
母乳中含有丰富的抗体，可以提高宝宝的免疫力。最初几天的黄黄的液体，也叫“初乳”，含有的抗体更加丰富，是非常有益宝宝健康的，一定要给宝宝吃。建议母乳喂养至少一年，如果因为种种原因无法实现，那至少保证六个月，以保证宝宝可以从母亲那儿得到足够的抗体。

2**均衡饮食，多吃水果蔬菜**
不建议盲目补充营养补充剂，而要通过营养膳食来增强宝宝的抵抗力。日常生活中要适当吃胡萝卜、青豆、草莓、橘子等这些富含VC的水果蔬菜。

3**睡饱睡好**
长期睡眠缺乏的宝宝容易抵抗力差。一般而言，新生儿需要18小时左右的睡眠，1岁左右的宝宝总共需要12～13小时睡眠，学龄前儿童需要10小时睡眠。如果宝宝大了以后开始不愿意白天睡午觉了，那要注意晚上提前安排入睡。

4**多锻炼**
对于1岁以内的宝宝，其实所谓的“锻炼”也就是醒着多趴、多爬，平时创造条件让宝宝多动，少抱。如果有条件，每天可以带宝宝出门去公园呼吸一下新鲜空气，晒晒太阳。

5**养成良好卫生习惯**
洗手、洗手、洗手！这个是最重要的全家卫生习惯，大部分的病毒都是通过接触传染的。接触宝宝之前大人要记得洗手。当宝宝大了，活动多了，平时也要记得给宝宝洗手，特别是每餐前后、出门回家、接触宠物后等。

6**谨慎使用抗生素**
抗生素只对细菌引起的疾病有效，对于病毒引起的疾病是没有效果的，而大部分婴幼儿疾病都是由于病毒引起的。作为父母，都不忍心孩子生病，但并不是一生病就用抗生素就是对宝宝好。一定要搞清楚孩子是什么情况，然后对症下药。

7**定期接种疫苗**
疫苗是帮助宝宝建立免疫防线很重要的手段，定期接种很有必要。

宝宝出生后的免疫系统是不完善的，而是通过接触病毒、导致生病来强壮自己的免疫系统。

**再来划重点！**

每个妈妈都舍不得宝宝生病，但要知道，生病本身就是宝宝提高免疫力的必经道路。作为父母，与其怕宝宝生病而过度保护，不如从源头抓起。
