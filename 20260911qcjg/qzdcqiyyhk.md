# 【“人民人”在昭通系列报道】紧握手中的接力棒

> 更新时间：2026-09-11 (UTC+8)

王天兵主任医师作为第二批医疗专家，接过第一批专家的爱心接力棒，刚刚抵达云南省昭通市第一人民医院就投入了紧张的工作和战斗，会诊、讨论、手术紧锣密鼓地进行。

“昨天为一位挤压综合征的危重病人进行了会诊，病人已经昏迷，出现心功能衰竭，我们迅速为他制定方案，进行了清创手术，清理了双下肢长时间受压而坏死的组织。”王天兵大夫说。

王天兵大夫作为国家卫生计生委委派的骨科专家，与同组的专家和昭通市第一人民医院创伤科的医护人员，一起为伤员拉起生命的安全网。

今天上午我们组做了3台手术，一台是股骨颈骨折，一台是盆骨骨折，还有一台是双小腿骨折。”上午在昭通市第一人民医院的工作刚刚结束，下午他又匆匆赶去昭通市第二人民医院，这里还有40名左右的病人。

王天兵大夫和专家们主要是要对病人情况进行会诊筛查，为符合手术指征的病人进行手术。

经过前期的奋力抢救之后，此次医疗专家救治工作重点发生转变，王天兵大夫说：“第一批专家的主要任务以损伤控制为主，全力挽救伤员的生命，防止出血和感染，对创口进行早期处理。作为第二批医疗组成员，我们的任务主要是在病人生命指征稳定后进行功能性重建的手术，为恢复患者功能进行治疗和处理。”

明天，还有5台手术等待着王天兵大夫，他牢牢握紧手中的接力棒，心怀大爱，奋勇向前。
